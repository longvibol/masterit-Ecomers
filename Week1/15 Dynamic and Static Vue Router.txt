1- Static Router Link : navigate by the path 
2- Dynamic Router Link : navigate by the name 

Ex: in index.js 

  {
    path: '/', ==> call static 
    name: 'home', ==> call name
    component: HomeView
  },

In App.vue : 

<template>
  <nav>
    <router-link to="/">Home</router-link> |
    <router-link to="/about">About</router-link>
    <router-link to="/register">Register</router-link>
    <router-link :to="{name: 'register'}">Register Two Called</router-link>
    <!-- <a href="/">Home</a>
    <a href="/about">About</a> -->
  </nav>
  <router-view/>
</template>

============================================================


This is the best easy way to put router:


 <router-link to="/">Home</router-link> |
